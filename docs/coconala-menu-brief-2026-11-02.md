# ココナラ英語メニュー作成サービス：Claudeへの引き継ぎ文

## 事実調査の要点（2026年11月2日確認）

### AI利用の規約
- 明文化されたAI関連の禁止は「AIによるイラスト作成を行うサービス」のみ。AI翻訳・AI文章生成を禁止する記載は出品禁止サービス一覧になかった（[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。
- ただし「AIイラスト以外のAI利用は公式に承認済み」とは言えない。2023年12月の公式案内はAI活用支援の姿勢を示すが、個別許可ではない（[公式ニュース](https://coconala.com/news/917)）。
- AI補助を明記した英語メニュー出品が実在する：「AI翻訳を補助的に利用し、原文・料理内容との整合を確認して英語表記案を提案」（[出品例](https://coconala.com/services/4468477)）、「AIを構成案と下書きの補助に使用。機械出力をそのまま納品せず、照合して整える」（[出品例](https://coconala.com/services/4420820)）。公開実在は運営承認の証拠ではない。
- 依頼者側の募集には「AIに書かせるはNG」とAI生成本文を禁止する例も実際にある（[募集ページの例](https://coconala.com/requests/categories/375)）。
- 利用規約に外部AIへ原稿を入力することへの包括的許可は確認できなかった。AI利用の同意と原稿入力の同意を分けて説明する（[利用規約](https://coconala.com/pages/terms_user)）。

### 飲食店の困りごと
- アレルギー：外食のアレルギー情報提供は義務ではないが、消費者庁はメニューへの表示を推奨（[消費者庁](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/assets/food_labeling_cms204_210514_01.pdf)）。義務8品目・推奨20品目の一覧あり。「表示がない＝含まれていないではない」（[消費者庁](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/efforts/assets/food_labeling_cms204_240509_02.pdf)）。
- 料理名の訳し方：JTAスタイルマニュアルが基準（英語優先＋ローマ字括弧、ヘボン式、tempura/matcha等の英語化済み語）（[JTA](https://www.mlit.go.jp/kankocho/content/001881928.pdf)）。観光庁ガイドラインに対訳語一覧（和食=Washoku (Japanese cuisine)等）（[観光庁](https://www.mlit.go.jp/kankocho/content/810003138.pdf)）。
- 翻訳だけでは文字数の違いでレイアウトが崩れる問題（[出品例の訴求点](https://coconala.com/services/4342800)）。
- 機械翻訳の既存メニューの不安（[ランサーズ](https://www.lancers.jp/menu/tag/%E5%96%AB%E8%8C%B6%E5%BA%97%E3%83%A1%E3%83%8B%E3%83%A5%E3%83%BC)）。

### リスクと対策
- 誤訳の責任：ココナラ規約上の責任分担条文は本次確認できず「不明」。認訳・公的文書は対象外と書き、「最終表記は店舗で確認」（[実在出品の書き方](https://coconala.com/services/4468477)）を出品文に反映する。
- アレルギー：店舗確認済み情報のみ転記（[実在出品も同じ方針](https://coconala.com/services/4388653)）。アレルゲンの追加判断をしない。定型注意文を入れる。混入完全防止は困難と消費者庁も明記（[消費者庁](https://www.caa.go.jp/policies/policy/food_labeling/food_sanitation/allergy/efforts/assets/food_labeling_cms204_240509_02.pdf)）。
- AI：生成イラスト・写真は使わない。虚偽の体裁にしない。返金保証の掲載は禁止（[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。
- メニュー改定に備え、更新は別途オプションと書き、無期限サポートと見なされないようにする。

## Claudeへの依頼

1. 上の調査を前提に、出品文（商品名・概要・FAQ）のドラフトを作ってほしい。方向性：飲食店の日本語メニューを訪日客向け英語メニュー（A4・1〜2ページPDF）に作り直す。AI翻訳を補助的に使い、出品者が照合・確認して納品すると明記。
2. 架空の居酒屋メニュー（20品程度）で見本を作る。アレルギー欄には店舗確認済みの仮の情報のみを置く。
3. 価格はA4・2ページ・20〜30品で5,000〜8,000円あたりから検討。カテゴリは「飲食店メニュー表作成」（最低2,000円）を第一候補に、出品前に運営確認する。
4. 修正2〜3回まで、原稿受領後3〜5日で初稿を基本条件にする。
