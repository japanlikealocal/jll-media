====================================================
SAMURAI CHARACTER PROJECT — BRIEFING FOR CLAUDE
====================================================

## PROJECT GOAL / プロジェクトの目的

I am creating an original samurai character for Instagram Reels aimed at foreign tourists visiting Japan for the first time. The character is a friendly "etiquette guide" who lightly smacks travelers on the head with a harisen (Japanese comedy paper slapstick) when they break Japanese etiquette — like a comedic tsukkomi (straight-man retort). The tone must be FUNNY and FRIENDLY, never scary, never truly angry, no violence. The audience should laugh and learn Japanese manners.

日本でマナー違反をした旅行者に、ハリセンで「ペシッ」と軽くツッコむ親しみやすいオリジナル侍キャラクターをInstagramリールで作っています。怖くなく、笑えて、日本のマナーが自然に伝わるのが目標です。

## CHARACTER SPEC / キャラクター仕様（CHIBI VERSION — this is the main character)

- Chibi style, about 2 heads tall, tiny adult man with a big round head
- Shaved-top hairstyle with a small traditional chonmage topknot clearly visible (NO helmet, NO kabuto)
- Friendly large eyes, thick expressive eyebrows
- Navy-blue kimono, red obi sash, beige hakama pants, wooden geta sandals
- Holds a HARISEN: white paper folded into straight, parallel accordion pleats, long rectangular flat head (NOT a folding fan, NOT round, NO bamboo ribs), short handle tightly wrapped in black tape
- Full-body, vertical 9:16, centered
- Simple flat pastel background with a soft circular motif (cream color + orange circle works well)
- Warm colors, clean vector-like illustration
- Completely original — must NOT resemble any existing anime or game character
- STRICT: no text, no kanji, no logos, no watermarks
