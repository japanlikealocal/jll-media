# ココナラPDF整形サービス：相場・AI規約・提案文

Claudeへの調査報告。確認日：2026年10月28日。日本語の案内文書を、支給原稿から読みやすいPDFに整える小規模な受注を想定する。以下は「公式ルール」「公開ページの掲載条件」「Perplexityの推奨案」を分けた報告であり、受注や運営審査の通過を保証するものではない。

## 結論と修正点

- **価格の修正**：公式の「チラシ作成・フライヤーデザイン」の最低サービス価格は4,000円。以前の3,000円案は、このカテゴリでは採用しないこと。パンフレット・カタログデザインは最低10,000円で、最低価格を避けるために内容と違うカテゴリを選ぶ行為も禁止されている（[公式最低価格表](https://coconala-support.zendesk.com/hc/ja/articles/360020963554-%E3%82%AB%E3%83%86%E3%82%B4%E3%83%AA%E3%81%94%E3%81%A8%E3%81%AE%E6%9C%80%E4%BD%8E%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9%E4%BE%A1%E6%A0%BC)、[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。
- **AI利用の判断**：公式はAI活用を一般的に支援する一方、「AIによるイラスト作成を行うサービス」を禁止している。今回の「文字・表・単純な図形のレイアウトをClaudeで支援し、人が確認してPDF納品する」方式について、確認した公式文書には明示的な許可・禁止を見つけられなかったため、「ココナラが個別に承認済み」とは言えない（[公式AIガイドライン案内](https://coconala.com/news/917)、[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)、[利用規約](https://coconala.com/pages/terms_user)）。
- **最初の売り方の提案**：高機能な印刷デザインではなく、「確定した日本語原稿の体裁整理」「閲覧・家庭印刷用PDF」「小さな範囲」に絞る。出品文と見本を完成させ、カテゴリとAI利用方法を運営に確認したうえで試すことを勧める。

## AI補助と出品ルールの確認

### 許容と断定できる範囲を分ける

- **AI全般が禁止ではない**：2023年12月の公式案内は、AIを使った業務効率化や品質向上を支援する姿勢を示している。ただし、これは今回のサービスへの個別許可ではない（[公式AIガイドライン案内](https://coconala.com/news/917)）。
- **AIイラストは別問題**：現行の出品禁止一覧には「AIによるイラスト作成を行うサービス」が明記されている。今回の見本と商品には生成イラストを含めず、文字・表・罫線・背景色などの文書レイアウトに限定する案を推奨する（[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。
- **掲載例は運営承認の証拠ではない**：公式は公開サービスを順次確認し、不適切な場合は修正や取り下げを実施するとしている。似た出品が存在するだけで、同じ制作方法が保証されるとは考えない（[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。

### 情報管理と説明

利用規約第71条は利用会員の個人情報の厳重管理と第三者への非開示等を定め、第18条は承諾範囲を超える個人情報の利用・提供・開示等を禁止している。確認した条文に、外部AI投入に関する包括的な許可は見当たらない（[利用規約](https://coconala.com/pages/terms_user)）。

したがって、本人とClaudeの運用では次を推奨する。これは法的適合性を保証する手順ではなく、最初の案件のリスクを抑えるための提案である。

- **制作方法**：「Claudeを使って構成・レイアウトを作成し、本人が原稿照合と最終確認をする」と事前説明する。「補助」とだけ書き、人がすべて手作業でデザインするように見せない。
- **入力の同意**：「AIを使うことへの同意」と「その原稿を外部AIに入力することへの同意」を分ける。初回は個人情報・機密情報のない原稿を優先し、必要なら氏名・住所等を仮の文字に置き換える。
- **権限と規約**：依頼者の了承だけで、第三者の個人情報、著作物、会社の機密資料まで自由に入力できるとは扱わない。利用するAIの設定・利用条件も確認し、確認していない「学習されない」「即時削除される」等は約束しない。
- **確認と納品**：原稿照合、改ページ、文字化け、日付・料金・申込先を本人が確認する。依頼者との連絡・原稿の受け渡し・納品はココナラ内で完結させる運用とする。

ココナラ外の連絡や取引への誘導、商用利用禁止素材の使用、他者の出品文のコピー等は禁止事項に含まれる。見本や出品文は独自に作り、使用フォント・素材の利用条件を確認すること（[出品禁止サービス](https://coconala-support.zendesk.com/hc/ja/articles/9517249749017--%E4%B8%80%E8%A6%A7-%E5%87%BA%E5%93%81%E7%A6%81%E6%AD%A2%E3%82%B5%E3%83%BC%E3%83%93%E3%82%B9)）。

### 出品前に運営へ確認する文章案

> 支給された確定原稿をもとに、ClaudeでHTML/CSSによる文字・表・罫線・背景色のレイアウトを作成し、出品者が内容照合・修正・最終確認をして日本語PDFを納品するサービスを検討しています。AI生成イラストや写真は使いません。AI利用は事前説明し、原稿の外部AI入力についても必要な確認を行います。この制作方法で出品可能でしょうか。また、添付のA4・2ページの教室案内見本と出品文に適したカテゴリ、および最低出品価格を教えてください。

運営への送信はまだ行っていない。見本と出品文を添付できる状態にして、本人から確認する想定である。

次は相場の断定ではなく、現在の体制で約束を守りやすくするための条件案。架空の料理教室案内を完成させ、差し替えテストと実作業時間の確認後に確定する。

| 項目 | 推奨する初期条件 |
|---|---|
| 商品名の方向性 | 支給原稿を読みやすい日本語の案内PDFに整えます |
| 基本範囲 | A4・2ページまで、原稿合計1,500字程度まで、文字・色・罫線・簡単な表のみ |
| 価格 | 総額4,000円案。ただし、実際に選ぶ適正カテゴリの最低価格を満たすこと |
| デザイン | 1案。見本に近い体裁の範囲 |
| 修正 | 依頼者都合の軽微な修正1回。指示をまとめて1回と数える。制作者の転記ミス等は別に訂正 |
| 日程 | 購入・原稿受領・制作条件合意がすべて揃ってから3日以内に初稿。最終納品は着手から5日程度を目安に、依頼者の確認日程を含めて事前合意 |

HTMLからPDFにできることと、依頼されたすべての納品形式に対応できることは分けて考える。例えば美容サロン募集ではPDFに加えてIllustrator等の編集元データ、別の募集では編集可能なCanvaテンプレートまで要求されていたため、PDFのみの体制では要件を満たさない（[美容サロン募集](https://coconala.com/requests/5319849)、[転記募集](https://coconala.com/requests/5329857)）。

```text
はじめまして。【募集名】の内容を拝見しました。ご支給の確定原稿をもとに、A4・2ページまで、見出し・余白・簡単な表を整えたPDFを制作します。架空の料理教室案内の見本を添付しました。料金は4,000円、修正1回込みです。ご購入・原稿受領・制作条件の合意後3日以内に初稿、着手から5日程度で最終納品を予定します（ご確認待ちを除く）。制作にはClaudeを活用し、私が原稿照合と最終確認を行います。個人情報等の外部AIへの入力は別途確認し、無断では行いません。ご希望の納品日をお知らせください。
```
