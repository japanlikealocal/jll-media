# 日本で店員に聞かれること：英語リール3本の事実確認

2026年11月23日確認。初めて日本を訪れる旅行者向け。判定の「正しい」は表現の意味や制度を確認できたという意味で、どの店でも同じ言い方をするという意味ではない。店や宿で違うことは「場合による」、全国的な頻度や公式に裏付けられない実際の聞かれ方は「確認できない」と記載。返答は台本用の自然な例。「はい／いいえ」で答えない質問には、その場で使える返し方を載せた。

### 免税：リールで省かない手順

- **買うとき：** 免税店でパスポートを提示して手続きし、税込価格を払う。返金先の登録などは店の案内に従う。対象購入額は原則、**同じ店・同じ日の税抜合計5,000円以上**。一括免税カウンターで合算できる等の例外がある。[観光庁の制度案内](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00021.html)・[観光庁の旅行者向けリーフレット](https://www.mlit.go.jp/kankocho/tax-free/content/001991231.pdf)
- **出国するとき：** 購入日から**90日以内**の出国時に、空港・港で税関確認を受ける。空港では、対象品を手元に用意し、航空会社に荷物を預ける前に手続きを済ませる。端末で検査が必要と表示されたら、商品を税関の指定場所で提示する。確認後に返金される仕組みで、税関窓口がその場で現金を渡すという意味ではない。[税関の英語案内](https://www.customs.go.jp/kaigairyoko/taxrefund.htm)・[観光庁の英語手順](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00028.html)
- **ドラッグストアで特に注意：** 一般物品と消耗品の区分、消耗品の50万円上限・特殊包装は廃止。それでも、日本で消費した商品は免税の返金対象にならない。税関確認は購入取引単位で、同じ取引のうち1点でも所持していないと、その取引全体で確認・返金を受けられない。[財務省の改正解説](https://www.mof.go.jp/public_relations/finance/denshi/202505/pageindices/index18.html)・[観光庁の制度案内](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00021.html)

### 店頭・フロントで使う際の補足

- **レジの言い換え：** 小売業向けの接客資料には「免税はご希望ですか？」「レジ袋は有料になりますが、ご入用でしょうか？」「お支払いは現金ですか、カードですか？」の例がある。この資料の免税金額欄は旧制度のため、参照するのは言い回しだけ。[小売業向けの多言語接客フレーズ集](https://welcome.japan-retail.or.jp/files/pdf/pdf_tools_phrase.pdf)・[観光庁の新制度案内](https://www.mlit.go.jp/kankocho/tax-free/page01_000001_00021.html)
- **お通しの金額例：** 串カツ田中の公式FAQには税込319円と表示される一方、公式サイト内の別ページには297円とある。このため全店一律の現行額とは断定せず、リールではGO TOKYOの目安「1人200〜1,000円」と「注文前に店で確認」を使う。[串カツ田中の公式FAQ](https://kushi-tanaka.com/contact/)・[別の公式FAQ](https://kushi-tanaka.com/contact-customer/)・[GO TOKYOの居酒屋ガイド](https://www.gotokyo.org/jp/story/guide/pub-grub-decoded-a-guide-to-japanese-izakaya/index.html)
- **宿泊税は全国一律ではない：** 京都市の例では、2026年3月以降、1人1泊の税抜宿泊料金が6,000円未満は200円、6,000円以上2万円未満は400円、2万円以上5万円未満は1,000円、5万円以上10万円未満は4,000円、10万円以上は1万円。東京の料金表と混同しない。[京都市公式の税額表](https://www.city.kyoto.lg.jp/gyozai/page/0000249302.html)・[東京都主税局](https://www.tax.metro.tokyo.lg.jp/kazei/leisure/shuk/shukuhakusha)

## 訪日客が会話で困ること

観光庁の令和7年度調査（2025年11月〜2026年1月、4,110件）では、「施設等のスタッフとのコミュニケーション」が15.4%で、旅行中の困りごとの2位。コミュニケーションで困った場所として飲食店を挙げた割合は38%。これは回答者全体の38%という意味ではなく、どのフレーズで困ったかの順位は確認できない。[観光庁の調査発表](https://www.mlit.go.jp/kankocho/news08_00039.html)・[調査結果PDF](https://www.mlit.go.jp/kankocho/content/001998583.pdf)

- **聞き取れないとき：** すみません、もう一度、ゆっくりお願いします。/ Sumimasen, mō ichido, yukkuri onegai shimasu. → Sorry, could you say that again more slowly?
- **選択肢を聞かれたとき：** 「一緒／別々」「現金／カード」には、なんとなく「はい」と返すより、希望を一語で返すと伝えやすい。例：「別々で」/ Betsubetsu de.、「カードで」/ Kādo de.
- **断りたいとき：** 袋や追加注文は「袋はいりません」「追加はありません」と対象を言うと明確。お通しは、いらないと言うだけで料金が外れるとは限らないので「その場合も料金はかかりますか？」まで聞く。[GO TOKYOの居酒屋ガイド](https://www.gotokyo.org/jp/story/guide/pub-grub-decoded-a-guide-to-japanese-izakaya/index.html)・[串カツ田中の公式FAQ](https://kushi-tanaka.com/contact/)
